About me:
Hello! My name is Blair and I'm a student interested in computer science, mathematics, and engineering. As an innovator, I enjoy using coding to solve problems and make everyday tasks easier. I’m also interested in integrating a variety of concepts in my code to improve efficiency and quality.  

 

I mainly code in C++ using Visual Studio Code. One project I built on X Code is a name generator that can select random names using a spinning wheel, shuffle people into a random order, and create random groups (it’s on App Store: Interactive Name Generator). I also make programs that solve word problems, which has helped me connect math with programming. Some platforms I use are Luogu and Code Forces. More recently, I have experimented with Arduino and circuits, giving me experience with both software and hardware. Interestingly, my experiences with mathematics influenced the way I approach programming. Math has trained me to think logically and look for patterns, and I've been able to apply that concept in programming by envisioning code as brain neurons.  

 

I am motivated by the process of finding efficiency. I enjoy solving challenging problems, debugging, and finding quicker solutions like improving time efficiency and minimizing code. I’m especially interested in how technology can take over repetitive tasks by using loops and eliminating variation error common in human work. My goal is to continue improving my programming and problem-solving skills and eventually take on more complex projects. I also want to work on my hardware skills and figure out how to use the breadboard correctly.
